# ecommerce_analytics_project-
E-Commerce Analytics Dashboard | SQL, PostgreSQL &amp; Python: Analyzed 5,000 orders, 800 customers, and 60 products to uncover revenue, profit, customer, product, category, and regional trends. Used SQL JOINs, CTEs, aggregations, and window functions, with Python for analysis and visualization.


# E-Commerce Analytics Dashboard

## Project Overview
An intermediate-to-advanced Data Analyst portfolio project using PostgreSQL, SQL and Python to analyze an e-commerce business.

## Dataset
- Customers: 800
- Products: 60
- Orders: 5,000
- Date range: 2024-01-01 to 2025-12-31

## Key Results
- Total Revenue: 10,502,035.28
- Total Profit: 1,840,022.11
- Repeat Customers: 793
- Best Category by Revenue: Furniture
- Best Region by Revenue: West

## Skills Demonstrated
- Relational database design
- SQL JOINs
- GROUP BY / HAVING
- Aggregations
- CTEs
- Window functions and ranking
- Running totals
- Customer analysis
- Product/category/region analysis
- Python Pandas analysis
- Data visualization
